# Bus Fare Challenge

- distanceKm (double)
- isPeak (bool)
- isStudent (bool)
- isSenior (bool)
- isWeekend (bool)

Compute: base 2.50 + (distance * 0.80).
Add 20% if isPeak.
Subtract 15% if isStudent, or 30% if isSenior (whichever is bigger, not both).
Subtract 10% if isWeekend.
Return "Final fare: GHS X.XX".
Add main() that tests 3 scenarios. Use final where appropriate.
